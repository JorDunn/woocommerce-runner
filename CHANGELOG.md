## [1.0.0] - 2026-08-15

### Added

- Initial release: the `wc-runner` CLI (default PHPUnit test mode with the
  exit-code contract, `--demo` seeded store, `--down`/`--destroy`
  lifecycle), read-only plugin mounts, MariaDB tmpfs with a `--persist`
  switch, opt-in Valkey object cache, WooCommerce version pinning, the
  `examples/hello-wc-runner` reference plugin, and the composite GitHub
  Action (`action.yml`).
